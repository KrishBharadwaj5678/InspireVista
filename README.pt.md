# ✨ InspireVista

**InspireVista** é um gerador simples, porém poderoso, de citações motivacionais baseado em Python, projetado para elevar seu ânimo e ajudar você a aproveitar o dia!

![InspireVistaDemo](https://github.com/KrishBharadwaj5678/Inspire-Vista/raw/main/InspireVistaDemo.png)

## 💫 Funcionalidades

| Funcionalidade            | Descrição                                                  |
| ------------------------- | ---------------------------------------------------------- |
| 🧠 Citações motivacionais | Coleção selecionada de citações inspiradoras               |
| ⚡ Rápido e leve           | Otimizado para alta velocidade e baixo consumo de recursos |

---

## 🧰 Tecnologias Utilizadas

| Tecnologia   | Finalidade                                                 |
| ------------ | ---------------------------------------------------------- |
| 🐍 Pitão     | Linguagem principal que alimenta o InspireVista            |
| 🌐 Streamlit | Interface web para o gerador interativo de citações        |
| 🔗 API       | Busca e integra citações motivacionais de forma automática |

## 🚀 Primeiros Passos

### 1️⃣ Clonar o Repositório



```bash id="v8x3qp"

```

