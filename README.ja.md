# ✨ インスパイアビスタ

**インスパイアビスタ** は、気分を高めて一日を前向きに過ごせるように設計された、シンプルでありながら強力な パイソン ベースの名言ジェネレーターです。

![インスパイアビスタデモ](https://github.com/KrishBharadwaj5678/Inspire-Vista/raw/main/InspireVistaDemo.png)

## 💫 機能

| 機能           | 説明                   |
| ------------ | -------------------- |
| 🧠 モチベーション名言 | 厳選されたモチベーション名言コレクション |
| ⚡ 高速 & 軽量    | スピードと軽量性に最適化されています   |

---

## 🧰 技術スタック

| 技術           | 用途                             |
| ------------ | ------------------------------ |
| 🐍 パイソン   | InspireVista を支えるコアプログラミング言語   |
| 🌐 Streamlit | インタラクティブな名言ジェネレーターのWebインターフェース |
| 🔗 API       | 名言をシームレスに取得・統合                 |

---

## 🚀 はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/InspireVista.git
```

### 2️⃣ フォルダへ移動する

```bash
cd InspireVista
```

### 3️⃣ 依存関係をインストールする

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを実行する

```bash
streamlit run app.py
```
