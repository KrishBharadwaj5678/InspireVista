# ✨ InspireVista

**InspireVista** это простой, но мощный генератор мотивационных цитат на Python, созданный чтобы поднимать настроение и помогать вам начать день с вдохновения!

![InspireVistaДемо](https://github.com/KrishBharadwaj5678/Inspire-Vista/raw/main/InspireVistaDemo.png)

## 💫 Возможности

| Возможность             | Описание                                                               |
| ----------------------- | ---------------------------------------------------------------------- |
| 🧠 Мотивационные цитаты | Подборка тщательно отобранных вдохновляющих цитат                      |
| ⚡ Быстро и легко        | Оптимизирован для высокой скорости и минимального потребления ресурсов |

---

## 🧰 Технологический стек

| Технология   | Назначение                                        |
| ------------ | ------------------------------------------------- |
| 🐍 Питон    | Основной язык программирования InspireVista       |
| 🌐 Streamlit | Веб-интерфейс для интерактивного генератора цитат |
| 🔗 API       | Получение и интеграция мотивационных цитат        |

## 🚀 Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/InspireVista.git
```

### 2️⃣ Переход в папку

```bash
cd InspireVista
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
